# 🗂️ Project Portfolio Directory

This repository contains a collection of my project work and documentation, covering data management, social-spatial research, geology, and data science. Each folder represents a standalone project with its own documentation and pipeline.

---

## 📁 1. [Data Management](https://github.com/Fajrimughni/project-portfolio/tree/main/projects/data-management-hcml)

A pipeline for managing large-scale digital files, including:
- Metadata extraction (name, extension, size, date)
- File type cleaning and classification (semi-automatic & ML-based)
- Classification evaluation
- File relocation into a structured folder system
- Logging and validation of the process

**Tools**: Python (`pandas`, `shutil`, `scikit-learn`), Jupyter Notebook  
**Documents**: `data-management-pc.ipynb`, `machine-learning.ipynb`, `pemindahan-file.ipynb`

---

## 📁 2. [Larantuka-2023](https://github.com/Fajrimughni/project-portfolio/tree/main/projects/larantuka-2023)

Documentation of geological field observations and analysis in Larantuka, East Nusa Tenggara (NTT), including:
- Spatial data of rock site locations
- Daily field observation notes
- Geological maps and site photos

**Tools**: QGIS, GPS Logger, Adobe Illustrator  
**Project Type**: Geological fieldwork

---

## 📁 3. [Lnob-2023](https://github.com/Fajrimughni/project-portfolio/tree/main/projects/lnob-2023)

A social-spatial research project related to *Leave No One Behind (LNOB)*. My role included:
- GIS assistance & spatial analysis
- Data processing for vulnerable groups
- Thematic visualization & accessibility analysis

**Tools**: ArcGIS/QGIS, Excel, Python  
**Output**: Accessibility maps, spatial analysis report

---

## 📁 4. [Patgtl-2022](https://github.com/Fajrimughni/project-portfolio/tree/main/projects/patgtl-2022)

Geotechnical field practice (PATGTL) with ITB, including:
- Slope stability analysis
- Rock logging and mechanical testing
- Mine slope design

**Tools**: RocScience, Surpac, Geoelectric surveys  
**Project Type**: Academic geotechnical project

---

## 📁 5. [Sistem Lahan-2022](https://github.com/Fajrimughni/project-portfolio/tree/main/projects/sistem-lahan-2022)

Analysis of land systems in Indonesia from a political ecology perspective:
- Literature study of Agrarian Law, concession systems, and tenure conflicts
- Spatial visualization of concessions and forest areas

**Tools**: QGIS, Power BI, Python  
**Project Type**: Land policy research & spatial visualization

---

## 📁 6. [Data Science Portfolio](https://github.com/Fajrimughni/data-science-portfolio)

A collection of data science projects during a bootcamp with Dibimbing.id, including:
- Exploratory Data Analysis (EDA)
- RFM Analysis and Clustering
- Content-based Recommendation System

**Tools**: Python, Scikit-learn, Streamlit  
**Main Notebooks**: `rfm_clustering.ipynb`, `recipe_recommender.ipynb`
